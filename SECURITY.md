# Security policy

Report a vulnerability through GitHub private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). Do not open a public issue or pull request for it.

Include what is affected, steps to reproduce, and the impact you see. You get an acknowledgement, and a fix or a decision, through the same private thread.

## Scope

The web apps in `apps/`, the services in `services/`, the packages in `packages/` and the deployment in `infra/`. Out of scope: third-party services, and servers or accounts that are not part of this repository.

Rules for handling secrets and permissions in code are in [security](docs/standards/security.md).
